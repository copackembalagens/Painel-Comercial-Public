Cloudflare Pages, conectado a este repositório no GitHub). Nenhum dado
sensível deve ser commitado aqui em texto plano — a lógica de cálculo e os
dados brutos ficam no repositório privado
[Painel-Comercial-Private](https://github.com/copackembalagens/Painel-Comercial-Private).

por perfil (Eduardo, Joice, Rubs, Geovana, Francyne, Gerencial) — cada
pessoa só acessa a sua.

Status: em construção — front-end ainda não implementado (ver histórico de
tarefas do projeto). Este placeholder existe para o Cloudflare Pages ter o
que publicar enquanto o site é desenvolvido.
